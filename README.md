## Commit Conventions

This project follows [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` — new feature
- `fix:` — bug fix
- `docs:` — documentation
- `style:` — formatting
- `refactor:` — code restructuring
- `test:` — tests
- `chore:` — tooling, deps, config
- `ci:` — CI/CD changes
- `perf:` — performance improvements
